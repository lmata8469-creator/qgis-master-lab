🧭 La meta no es solo que el mapa se vea bonito

La meta es producir un mapa correcto, entender de dónde salen los datos, reconocer sus limitaciones y poder explicar qué significa para un problema real.

Directorio práctico
Complementos para tareas concretas

¿Qué complemento necesito?

Busca una tarea, revisa qué hace la herramienta y abre su ficha oficial. Antes de instalarla, confirma la compatibilidad con tu versión de QGIS y lee las condiciones de uso de los datos y servicios que vayas a utilizar.

Cómo usar este directorio
1. Busca por nombre o tarea. 2. Lee “Para qué sirve” y “Precauciones”. 3. Pulsa “Ver ficha oficial”. 4. Instala desde el administrador de complementos dentro de QGIS, salvo que la documentación oficial indique otra cosa.
Nota de compatibilidad y calidad
El catálogo cambia con las versiones de QGIS. No todos los complementos funcionan en todos los equipos. Para un trabajo técnico, verifica autor, mantenimiento, versión mínima, documentación, fecha de los datos y permisos de uso antes de confiar en el resultado.

Práctica integradora
Proyecto final paso a paso

Construye tu primer mapa ambiental

Caso didáctico: identificar escuelas cercanas a un río para practicar herramientas de análisis. No uses datos inventados como evidencia real: esta práctica enseña el procedimiento, no demuestra un riesgo ambiental.

La pregunta del proyecto
¿Qué escuelas se encuentran a menos de 500 metros de un río? Para responder necesitas datos correctos, un sistema de coordenadas adecuado y documentar tus decisiones.

Lista de control para entregar

Importante para un trabajo profesionalLa distancia de 500 m es un criterio ilustrativo, no una norma universal ni una definición automática de riesgo. Justifica siempre el umbral con el objetivo, el contexto y la norma o bibliografía aplicable.
